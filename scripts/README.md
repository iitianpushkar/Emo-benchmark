# Script catalog

All commands run from the repository root. You can use the grouped path below or
`python -m scripts <filename_without_py> [arguments]`.

| Group | Purpose |
|---|---|
| [data](data/README.md) | Prepare MELD indexes and conflict datasets |
| [extraction](extraction/README.md) | Model embedding extractors, chunk runners, and merge utilities |
| [classification](classification/README.md) | Train and evaluate the shared emotion MLP |
| [pruning](pruning/README.md) | Reusable token and frame selection algorithms |
| [fusion](fusion/README.md) | Modality embedding fusion and alpha sweeps |
| [ablation](ablation/README.md) | Visual/text ablations and fixed-classifier comparisons |
| [conflicts](conflicts/README.md) | Video/utterance conflict experiments |
| [information_horizon](information_horizon/README.md) | Decoder-depth token information interventions |
| [analysis](analysis/README.md) | Cross-experiment aggregation and sample alignment |
