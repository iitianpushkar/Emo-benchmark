# Attention Analysis

Diagnostic analyses of frozen model attention. Attention is reported as an
internal routing signal, not as a causal explanation of a prediction.

- [Qwen2.5-VL-3B on CMU-MOSEI](qwen2_5_vl_3b_mosei_last_query/README.md):
  head-averaged decoder attention from the final prompt-token query at every
  language-model layer, with temporal and spatial video-token heatmaps.
