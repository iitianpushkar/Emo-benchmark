# Baselines

Full-token Qwen baselines and alternative visual/VLM encoder comparisons.

[All experiments](../README.md)

- [qwen2_5_vl_3b_shared](qwen2_5_vl_3b_shared/README.md): Full video + utterance Qwen baseline. Contains the trained MLP, per-class predictions, embeddings, extraction chunks, and curated figures.
- [qwen2_5_vl_3b_visual_only](qwen2_5_vl_3b_visual_only/README.md): Configuration for the original visual-feature baseline; local results are not bundled here.
- [tdv_dino_ibot](tdv_dino_ibot/README.md): Standalone Kaggle notebook comparing DINO, iBOT, and TDV encoder backbones.
